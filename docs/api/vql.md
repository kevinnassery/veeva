# Vault Query Language (VQL)

Search your data quickly and efficiently with VQL.

[Overview](/vql/overview)[Get Started](/vql/getting-started)

You can use **Vault Query Language (VQL)** to access, retrieve, and interact with Vault data. Although VQL queries share most of the same syntax as Structured Query Language (SQL), VQL allows you to perform queries specifically for Vault data.
