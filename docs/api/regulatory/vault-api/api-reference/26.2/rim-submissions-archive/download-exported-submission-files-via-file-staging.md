# Download Exported Submission Files via File Staging

Once your submission export job has been successfully completed, you can download the files from [file staging](/regulatory/vault-api/guides/file-staging).

#### Prerequisites

Before downloading the files, the following conditions must be met:

* The submission export job must have been successfully completed.
* The API user must have a permission set which allows the *Application: File Staging: Access* permission.

#### Downloading the Files

The exported submission is packaged in a ZIP file on file staging. [Learn more](/regulatory/vault-api).
