# FIND Scopes & DISTANCE

By default, `FIND` queries search all picklist fields and document or object fields with data type String (*Text*, *LongText*, and *RichText* fields). This is equivalent to the default [`SCOPE PROPERTIES` option](/vql/functions-options/find-scopes-distance/scope-properties). Use search options with `FIND` to scope the search to a specific text field or document content.

* [DISTANCE](/vql/functions-options/find-scopes-distance/distance/)
* [SCOPE ALL](/vql/functions-options/find-scopes-distance/scope-all/)
* [SCOPE CONTENT](/vql/functions-options/find-scopes-distance/scope-content/)
* [SCOPE Fields](/vql/functions-options/find-scopes-distance/scope-fields/)
* [SCOPE PROPERTIES](/vql/functions-options/find-scopes-distance/scope-properties/)
