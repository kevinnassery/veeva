# Object Attachment Fields

*Attachment* fields allow you to attach a file to a field on an object record. The value of an *Attachment* field is the file handle for the file. Learn more about [Attachment fields in Vault Help](https://platform.veevavault.help/en/gr/15057).

You must download an *Attachment* field file in order to view or edit its content. You can use the following endpoints to download or update *Attachment* field files.
