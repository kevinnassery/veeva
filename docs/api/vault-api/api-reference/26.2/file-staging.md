# File Staging

The following endpoints allow you to create and manage files and folders in your Vault's file staging. Learn more about [file staging in Vault Help](https://platform.veevavault.help/en/gr/38653). To upload files larger than 50MB, see [Resumable Upload Sessions](/vault-api/api-reference/26.2/file-staging/resumable-upload-sessions). You must have the *Application: File Staging: Access* permission to use the File Staging API.
