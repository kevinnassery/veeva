# Document Locks

A document "lock" is analogous to "checking out a document" but without the file attached in the response for download. To download the document file after locking it, use the [Download Document File](/vault-api/api-reference/26.2/documents/retrieve-documents/download-document-file) endpoint.

Learn about [Document Checkout (Locks)](https://platform.veevavault.help/en/gr/162) in Vault Help.
