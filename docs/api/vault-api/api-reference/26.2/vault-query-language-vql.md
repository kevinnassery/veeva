# Vault Query Language (VQL)

When an application invokes a query call, it passes in a **Vault Query Language (VQL)** statement (a SQL-like statement) that specifies the object to query (in the `FROM` clause), the fields to retrieve (in the `SELECT` clause), and any optional filters to apply (in the `WHERE` and `FIND` clauses) to narrow your results. Learn more in the [VQL documentation](/vql/overview).
